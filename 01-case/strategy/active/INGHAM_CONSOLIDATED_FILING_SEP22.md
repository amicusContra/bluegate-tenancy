# THE CONSOLIDATED APPROACH

## Problem:
You have 7 active cases (+ 1 held) involving overlapping respondents and overlapping evasion evidence. Filing the same exhibits separately in each case means 7× the paper, 7× the clerk time, and no judicial recognition of the PATTERN.

## Solution:
**File ONE master motion with ONE exhibit packet in the civil cases (2026-4349-CZ + 2026-4301-CZ), then REFERENCE it in the PPO filings.**

Michigan courts allow cross-referencing between cases in the same court. MCR 2.107(G) allows incorporating by reference. The key is:

1. **The civil cases are YOUR cases** — you have full standing to file motions
2. **The PPO cases are DaSean's** — you file service proof there, but the heavy motion lives in your civil cases
3. **The evidence is identical** — same respondent (Banks), same addresses, same evasion, same 7-channel blast
