## HOW TO RUN THESE SEARCHES

### Option A: PACER Case Locator (Recommended — fastest)
1. Go to https://pcl.uscourts.gov
2. Click "Party Search" (not Case Search)
3. Enter Last Name, First Name
4. **DO NOT select a court type** — this searches ALL courts
5. Click Search
6. Cost: $0.10 per results page

### Option B: Individual Court CM/ECF (More detail)
- MIED (civil/criminal): https://ecf.mied.uscourts.gov
- MIEB (bankruptcy): https://ecf.mieb.uscourts.gov — ALREADY DONE
- 6th Circuit: https://ecf.ca6.uscourts.gov

### Option C: RECAP/CourtListener (Free but incomplete)
- https://www.courtlistener.com — search party names
- Free, no account needed
- Only has cases that someone already pulled from PACER
- Good for a quick pre-check before spending $0.10
