## WHY "OCEAN" IS WORSE THAN "CONSPIRACY"

### If It Were a Conspiracy (Single Enterprise)
- One RICO case, one set of defendants, one trial
- Defense: "We didn't coordinate with the Smiths"
- Burden: Must prove Banks and Smiths agreed to act together
- Risk: If conspiracy fails, both clusters walk

### Because It's an Ocean (Independent Predators)
- Multiple cases, multiple jurisdictions, multiple agencies
- No single defense works against all attackers simultaneously
- Each cluster's fraud independently supports the other's scheme
- The SYSTEM failure is the story — not individual bad actors

### The Systemic Failure

| Jurisdictional Seam | What Falls Through |
|---------------------|-------------------|
| Wayne vs. Macomb Counties | Smith addresses span both; no shared database |
| State vs. Federal courts | BK filed federally; property fraud is state crime |
| Family vs. Criminal courts | Custody in family; fraud in criminal; no cross-reference |
| Education vs. Court system | Banks controls enrollment; courts control custody; neither checks the other |
| BK vs. Property records | Trustee searches by name "Smith" — misses "King" properties |
| SNAP vs. BK filings | DHS doesn't check BK schedules; BK court doesn't check SNAP |

### Each Predator Benefits From the Other's Scheme

| Banks Benefits From Smith Fraud | Smith Fraud Benefits From Banks |
|--------------------------------|-------------------------------|
| Children enrolled at PCA = revenue | Banks' "school" gives custody argument legitimacy |
| Shayla's custody control = stable enrollment | Banks' board judges provide judicial protection |
| Multiple addresses = harder to track children | Enterprise's resources fund legal defense |
| Family chaos = no organized parent opposition | PAC money = political cover for family court judges |

**Neither cluster needs to know about the other for both to benefit.**

This is not conspiracy. This is **ecosystem predation** — multiple
species feeding on the same prey in the same habitat, each adapted
to exploit a different vulnerability.
