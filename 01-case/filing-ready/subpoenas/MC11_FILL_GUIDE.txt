PROCESS -- HOW TO SEND THESE
================================================================

OPTION A: Certified Mail (cheapest)
1. Print MC 11 form (filled out) + attachment for each
2. Make a copy for your records
3. Go to USPS, send certified mail with return receipt
4. Keep the green receipt card when it comes back
5. The signed return receipt IS your proof of service
6. Cost: ~$8-10 per subpoena

OPTION B: Process Server (fastest, most bulletproof)
1. Give ABC Process Service the packet
2. They serve personally and file proof of service
3. Cost: ~$50-75 per subpoena
4. Best for Banks/PCA (he's slippery)

OPTION C: Hybrid
- Certified mail for carriers and Lake Trust (institutions
  accept mail, no games)
- Process server for PCA/Banks (he's a defendant, serve
  him in person for maximum impact)
