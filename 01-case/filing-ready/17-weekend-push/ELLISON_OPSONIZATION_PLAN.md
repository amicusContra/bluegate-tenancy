### ✅ LEGAL (passive observation, public data)

| Activity | Why Legal |
|----------|----------|
| DNS queries (A, MX, TXT, NS, SOA, PTR, CNAME) | Public records — anyone can query DNS |
| HTTP HEAD/GET requests to public pages | Normal web browsing |
| SSL certificate inspection | Certificates published to CT logs by DESIGN — that's how CT works |
| WHOIS lookups | Public registration data |
| robots.txt and sitemap.xml reading | Published BY THE SITE for indexing |
| Certificate Transparency log monitoring (crt.sh) | Public logs, designed to be monitored |
| Wayback Machine archival | Public web archival service |
| Google Alerts for domain/name | Public search monitoring |
| Shodan/Censys lookups | They index publicly exposed services |
| Publishing findings from public sources | First Amendment |
| Sending factual notifications to agencies | Petitioning government |
| Monitoring DNS changes (SOA serial) | Public records — checking if DNS changes |
| Monitoring sitemap changes | Public file — checking if pages added/removed |

| Attempting to log into cPanel, WebDisk, or any admin interface | **CFAA** — unauthorized access (18 USC § 1030) |

| Port scanning the server | Legally gray, could trigger CFAA |
| Intercepting, redirecting, or modifying traffic | **Wiretap Act** (18 USC § 2511) |

| Accessing the M365 tenant in any way | CFAA — unauthorized access |

Public archival. Legal. Creates timestamped record.

### 5. Google Cache Monitoring

public-facing site looked like at last crawl.

### 7. HTTP Header Monitoring

If the stack changes (new PHP version, new server, new session
config), it indicates platform updates.
