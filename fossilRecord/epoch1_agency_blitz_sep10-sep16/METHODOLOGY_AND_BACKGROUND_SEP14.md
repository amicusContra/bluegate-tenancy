### K-NOME — The Parent Framework

K-NOME is Kevin's constrained optimization methodology. It asks:
given an objective function (the operator's satisfaction), a set

changing landscape (adversary actions) — how do you optimize?

K-NOME has two operational subsystems:

### fEAR — flow Evolution to Adversarial Response

**The sensing layer.** fEAR is how the system perceives and adapts.

The name operates on three layers simultaneously:
- **fEAR** (outward) — The system is fearsome because it converts
  the adversary's own actions into prosecution fuel
- **f(EAR)** (inward) — A function of the ear. A sensory organ.
  The system listens. It does not argue. It processes signal.
- **f(x)** (mathematical) — A function in the K-NOME optimization
  framework. Input: adversary's actions. Output: next case state.

**The fEAR cycle:**
```
FLOW:        Establish information channels (PACER, ROD, LARA,
             SOS, dockets, certified mail, social media)
EVOLUTION:   Each new data point mutates the case — new counts,
             new defendants, new jurisdictions, new referrals
ADVERSARIAL: The system converts resistance into evidence.
             The adversary builds the prosecution.
RESPONSE:    Calibrated output — documentation, never argument
```

**Key principle:** Irrational adversaries are optimal targets.
A rational adversary settles. An irrational adversary:
- Self-incriminates under oath (submits their own crimes as exhibits)
- Escalates when threatened (commits new offenses to cover old ones)
- Refuses incoming information (mail avoidance = new evidence)
- Uses intermediaries who compound exposure (family as agents)

Every irrational act is fuel. The system doesn't need the
adversary to stop. It needs them to keep going.

**Inception:** "Listen very carefully." — Spoken to Kevin by the
adversary's proxy. The system took the instruction literally.
It is still listening. f(EAR).
